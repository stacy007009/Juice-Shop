# Juice-Shop
Цей репозиторій містить описи проходження навчальних завдань з веб-безпеки у форматі Markdown зі скріншотами. Матеріали створені в рамках практичного курсу з інформаційної безпеки для закріплення концепцій OWASP Top 10 на прикладах WebGoat та OWASP Juice Shop. Кожен опис включає постановку задачі, хід виконання, знайдені вразливості та висновки, а в окремих випадках — опис труднощів і невдалих спроб з поясненням причин. Завдання виконувались у власному віртуальному середовищі з використанням Docker, Burp Suite та DevTools браузера для аналізу трафіку й коду застосунків. Структура репозиторію відображає окремі лабораторні роботи та категорії OWASP Top 10, до яких належить кожне завдання.
